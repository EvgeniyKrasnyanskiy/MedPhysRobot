# 🗺️ Roadmap проекта MedPhysRobot

Документ описывает стратегические направления развития, запланированные функции и технические улучшения Telegram-бота MedPhysRobot.

---

## 🎯 Ближайшие планы (Краткосрочные задачи / v1.1)

### 1. 🔘 Интерактивные Inline-кнопки для администраторов
- [ ] Добавление кнопок быстрых действий под пересылаемыми сообщениями в админ-чате:
  - `[📢 В канал]` — публикация в канал в один клик.
  - `[👥 В PRO-группу]` — пересылка в подходящий топик.
  - `[🔇 Мьют 2ч]` / `[🚫 Бан]` — быстрая модерация без ручного ввода команд со смартфона.
- [ ] Кнопка подтверждения действий (защита от случайных нажатий).

### 2. 🛡️ Защита от спама и флуда (Rate Limiting)
- [ ] Реализация `ThrottlingMiddleware` в aiogram для личных сообщений (защита от спама командами и флуда файлами).
- [ ] Автоматический временный мут при превышении порога (например, более 5 сообщений за 5 секунд).

### 3. 📝 Указание причин модерации
- [ ] Поддержка аргументов причин в командах: `/mute 2h спам`, `/ban нарушение правил чата`.
- [ ] Отправка пользователю понятного уведомления с указанием причины и срока.
- [ ] Расширенное логирование в `LOG_CHANNEL_ID` с фиксацией причины и инициатора.

---

## 🚀 Среднесрочные задачи (Развитие функционала / v1.2)

### 4. ⚡ Переход на асинхронную БД (`aiosqlite`) и оптимизация SQLite
- [ ] Миграция синхронного `sqlite3` на `aiosqlite` для предотвращения блокировок event loop при высокой нагрузке.
- [ ] Включение режима WAL (`PRAGMA journal_mode=WAL;`) и безопасных таймаутов блокировок.

### 5. 🗂️ Динамическое управление топиками и ключевыми словами
- [ ] Перенос словаря ключевых слов из кода в базу данных или конфигурационный файл.
- [ ] Админ-команды для управления топиками прямо из Telegram:
  - `/topics list` — список привязанных тем и ключевых слов.
  - `/topics add <topic_id> <keywords>` — добавление или обновление темы без перезапуска бота.

### 6. 📊 Статистика и аналитика обращений
- [ ] Команда `/stats` для администраторов:
  - Количество входящих обращений за день / неделю / месяц.
  - Среднее время ответа дежурных администраторов.
  - Самые частые категории вопросов и активность пользователей.

---

## 🏗️ Долгосрочные планы (Архитектура и масштабирование / v2.0)

### 7. 🌐 Режим Webhook (Production Deployment)
- [ ] Опциональная поддержка запуска через Webhook (на базе `aiohttp` / `FastAPI`) вместо Polling для снижения задержек и экономии ресурсов сервера.
- [ ] Автоматическая настройка SSL и проверка секрета Telegram (`secret_token`).

### 8. 🤖 Интеллектуальная категоризация (NLP / LLM-классификация)
- [ ] Опциональное подключение локальной или облачной языковой модели для более точного определения топика PRO-группы по смыслу сообщения, а не только по жестким ключевым словам.
- [ ] Автоматические ответы на типовые частые вопросы (FAQ) с возможностью перевода на живого оператора.

---

## 📈 История изменений
- **v1.0.1** (Октябрь 2026):
  - Исправлена пересылка пакетов файлов и документов (`InputMediaDocument`, `InputMediaAudio`).
  - Устранен разрыв медиагрупп через debounce в `AlbumMiddleware`.
  - Добавлено редактирование сообщений в канале и PRO-группе (`/channel <id>`, `/pro <id>`).
  - Устранена плашка `Forwarded` при публикации контента через `copy_message`.
  - Добавлены короткие алиасы команд `/pro` и `/channel`.
  - Обновлена документация и расширена справка для администраторов.
